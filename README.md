# Dashboard de Gestão Financeira e Manutenção de Frotas

## Sobre o projeto

Projeto de Business Intelligence desenvolvido em Power BI com o objetivo de facilitar o acompanhamento de indicadores financeiros e operacionais relacionados à manutenção de frotas.

O dashboard permite visualizar informações gerenciais, acompanhar o andamento das ordens de serviço e apoiar a tomada de decisões por meio de indicadores e visualizações interativas.

## Objetivos

- Centralizar informações financeiras e operacionais.
- Facilitar o acompanhamento das despesas de manutenção.
- Monitorar o andamento das ordens de serviço.
- Transformar dados em informações visuais para apoiar decisões.

## Tecnologias utilizadas

- **Power BI:** desenvolvimento dos dashboards e visualizações interativas.
- **SQL Server:** consulta e extração de dados.
- **DAX:** criação de medidas e indicadores.

## Funcionalidades

- Visualização de indicadores financeiros.
- Acompanhamento de despesas relacionadas à manutenção.
- Monitoramento das ordens de serviço.
- Análise de informações por meio de filtros e gráficos interativos.
